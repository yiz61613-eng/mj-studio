🎬 漫剧直出工作台 · 使用说明

分镜 → 参考图 → 画布视频节点，一条龙自动建好。生成按钮永远由你自己点。

① 首次准备（只做一次）

  1. 双击安装器 漫剧直出工作台-安装程序.exe，允许管理员权限；装完桌面会出现「漫剧直出工作台」图标
  2. 直通服务已设为开机自启（后台静默运行，无需理会）
  3. 浏览器重启一次：Edge / Chrome 会自动出现扩展 Runroll Bridge（画布连接器）
  4. 首次打开工作台需授权激活：把屏幕上的机器码发给管理员，输入他给的授权码即可

② 日常出片三步

  1. 导入原料：顶部「导入分镜 MD」选分镜文件，「📁 导入参考图文件夹」选素材包（人物/场景/道具/音频自动分类挂载）
  2. 🌉 画布直通：右上角打开直通面板 → 选择画布（Runroll / UpDream，需在浏览器打开画布页并登录）→ 模型自动识别，选一个（默认 Seedance 2.0 低价·全能参考）→ 点「⚡ 一键直通」，节点、连线、参考全部自动建好
  3. 去画布点生成：打开画布检查一遍，自己点生成（费用走你自己的账号，工具绝不代点）
⚠ 素材在直通时会自动同步到本机服务，不需要摆目录、不需要 AI 参与。但分镜 MD 和素材包本身要自己拿U盘/网盘带过来，在工作台里导入一次即可（进度自动保存在浏览器里）。

③ 常见问题

  1. 「素材服务未连接」：服务没在跑。重启一次电脑即可自启；或到 %LOCALAPPDATA%\MjStudio 双击 run-server.vbs
  2. 「未检测到画布页」：先在浏览器打开 Runroll/UpDream 画布并登录；再确认扩展已启用（地址栏输入 edge://extensions 查看）
  3. 扩展没有自动出现：浏览器策略被拦时按手动方式：扩展页开「开发者模式」→「加载解压缩的扩展」→ 选 %LOCALAPPDATA%\MjStudio\server\extension 文件夹
  4. 画布上要清空重来：直通面板里勾选「先清空画布」再一键直通
  5. 想卸载：%LOCALAPPDATA%\MjStudio\uninstall.cmd，再删掉桌面图标
